# ⚽ Futebol Português — Base de Dados

## 📌 Sobre o projeto

Este projeto foi desenvolvido no âmbito da disciplina de **Programação e Sistemas de Informação (PSI)**, com o objetivo de criar uma base de dados relacional sobre alguns dos jogadores mais marcantes que passaram pelo futebol português.

A base de dados permite organizar informação sobre jogadores, clubes, épocas desportivas, estatísticas e avaliações.

## 🎯 Objetivos

- Conhecer jogadores importantes do futebol português.
- Criar e organizar uma base de dados relacional.
- Aplicar conhecimentos de SQL.
- Desenvolver o Modelo Entidade-Relação (MER) e o Modelo Relacional (MR).
- Realizar consultas para pesquisar e analisar os dados.
- Utilizar diferentes ferramentas digitais no desenvolvimento e apresentação do projeto.

## 🗄️ Estrutura da base de dados

A base de dados chama-se `futebol_portugal` e é constituída por cinco tabelas:

| Tabela | Descrição |
|---|---|
| `Jogador` | Guarda os dados dos jogadores. |
| `Clube` | Contém informações sobre os clubes. |
| `Epoca` | Regista as épocas desportivas. |
| `Passagem` | Regista a passagem dos jogadores pelos clubes e as respetivas estatísticas. |
| `Avaliacao` | Guarda prémios, notas e observações sobre os jogadores. |

## 🏆 Jogadores e clubes

O projeto inclui jogadores como Eusébio, Luís Figo, Cristiano Ronaldo, Deco, Ricardo Carvalho, João Moutinho e Hulk.

São também representados três clubes portugueses:

- Sporting Clube de Portugal
- Sport Lisboa e Benfica
- Futebol Clube do Porto

## 💻 Ferramentas e tecnologias utilizadas

Durante o desenvolvimento do projeto, foram utilizadas as seguintes ferramentas:

- **Visual Studio Code:** edição, programação e organização do código SQL.
- **ChatGPT:** apoio à programação, correção de erros e esclarecimento de dúvidas.
- **Canva:** criação e edição da apresentação visual do projeto.
- **Google Docs:** elaboração e organização da documentação e do relatório.
- **GitHub:** armazenamento, organização e partilha dos ficheiros do projeto.
- **DB Diagram:** criação e representação visual do modelo da base de dados.
- **ERD:** representação e análise do Modelo Entidade-Relação (MER).
- **XAMPP:** ambiente de apoio à execução e gestão da base de dados MySQL.
- **SQL:** linguagem utilizada para criar, organizar, relacionar e consultar os dados.

## 🔎 Funcionalidades

A base de dados permite:

- Consultar os jogadores registados.
- Consultar os clubes e as épocas desportivas.
- Visualizar as passagens dos jogadores pelos clubes.
- Consultar estatísticas, como jogos, golos e assistências.
- Calcular e ordenar o total de golos registados por jogador.
- Organizar a informação através de relações entre tabelas.
